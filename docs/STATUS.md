## Доступ GitHub

При обычном запуске в sandbox `gh auth status` ошибочно показывал недействительный токен из-за сетевого ограничения. Разрешённый сетевой запрос подтвердил доступ; GitHub API вернул текущий логин `MostViable`, а `gh auth status` подтвердил вход через keyring. Удалённый репозиторий создан. Публикация остаётся открытым продуктовым решением из-за названия и лицензии.
