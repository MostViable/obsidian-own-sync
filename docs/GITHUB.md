# Работа через GitHub

GitHub — основное место для исходного кода, обсуждения задач и проверки изменений проекта. Отдельно от этого GitHub может быть **пользовательским хранилищем заметок** через плагин. Эти роли не смешиваются: репозиторий проекта не хранит vault пользователей.

## Репозиторий проекта

- Публичный репозиторий создаётся после выбора имени и лицензии. Рабочее имя локальной папки — `obsidian-own-sync`.
- Основная ветка — `main`. Изменения функций и протокола проходят через отдельные ветки и pull requests.
- Issues фиксируют конкретный результат, критерии готовности и известные ограничения. Дорожная карта в [ROADMAP.md](ROADMAP.md) показывает порядок работ.
- CI должен проверять сборку плагина, форматирование и тесты механизма; после появления сервера — сборку Rust и интеграционные сценарии.
- Релизы плагина и сервера версионируются отдельно. Изменение формата синхронизации требует заметки о совместимости и миграции.

## Пользовательский GitHub-режим

- Каждый vault использует отдельный приватный репозиторий пользователя.
- Плагин запрашивает доступ только к выбранному репозиторию. Секреты остаются на устройстве пользователя и не попадают в коммиты.
- Принудительное обновление ветки и тихое удаление конфликтующих изменений запрещены правилами проекта.

## Текущее ограничение

Локальный `gh auth status` сообщил о недействительном токене. До повторного входа в GitHub CLI нельзя проверить создание remote и issues из этого окружения. Состояние доступа отслеживается в [STATUS.md](STATUS.md).
