# Own Sync for Obsidian

Own Sync — независимый проект плагина для Obsidian. Он не связан с командой Obsidian. Основной сценарий — синхронизация через **свой сервер на VPS** с шифрованием данных на устройствах. Приватный репозиторий GitHub рассматривается как дополнительный способ хранения с читаемыми Markdown-файлами **после self-hosted релиза**. Пользователь управляет своим хранилищем сам.

## Состояние

Проект находится на раннем этапе реализации. Есть собираемый каркас плагина, Rust-сервер с проверкой доступности `/healthz`, SQLite-хранилище и выключенный по умолчанию экспериментальный HTTP API. Синхронизация файлов из Obsidian, клиентское шифрование и пользовательские общие vault ещё не реализованы. Документы фиксируют принятые решения, открытые вопросы и порядок реализации.

## Цель первой версии

Установить плагин на компьютер и телефон, подключить один и тот же vault на личном VPS и синхронизировать заметки, вложения и выбранные настройки. Первый публичный релиз также должен включать историю версий, восстановление, конфликты и общие vault. [Базовый MVP](docs/MVP.md) остаётся внутренним этапом проверки, а не публичным релизом.

Синхронизация — не резервная копия. В проекте будут отдельные инструкции по созданию и восстановлению копий данных.

## Сеть и учётные записи

Плагин обращается только к адресу сервера, который указал пользователь. Для этого нужен собственный сервер; аккаунт проекта не потребуется. Запланированный после первого релиза GitHub-режим потребует аккаунт GitHub и отдельный приватный репозиторий. Пока плагин умеет лишь вручную проверить доступность сервера и права токена на тестовый vault. Клиентская телеметрия не планируется.

В первом релизе запланировано шифрование на устройстве до отправки на VPS. В более позднем GitHub-режиме файлы будут оставаться читаемыми в приватном репозитории; безопасность этих двух режимов различается.

## Локальная разработка

- Плагин: `npm ci && npm run build`. Сборка создаёт `main.js` рядом с `manifest.json`.
- Сервер: `cargo run --manifest-path server/Cargo.toml`. По умолчанию он слушает `127.0.0.1:8787`; адрес можно задать через `OWN_SYNC_BIND`. Для доступа с другого устройства понадобится HTTPS через reverse proxy.
- В тестовом vault скопировать `manifest.json` и `main.js` в `.obsidian/plugins/own-sync/`, затем включить плагин в Obsidian 1.11.4 или новее. Указать адрес своего сервера и выполнить команду **Check server connection** или нажать одноимённую кнопку в настройках. Для проверки прав на тестовый vault следовать [инструкции bootstrap](docs/BOOTSTRAP.md).

Обе проверки выполняются только по команде пользователя. Экспериментальный API сервера уже принимает непрозрачные пакеты, но плагин не отправляет ему файлы или ключи. Разрабатывайте и проверяйте плагин только на отдельном тестовом vault.
