# Own Sync for Obsidian

Own Sync — независимый проект плагина для Obsidian. Он не связан с командой Obsidian. Цель — синхронизировать хранилище через **свой приватный репозиторий GitHub** или **свой сервер на VPS**. Пользователь выбирает место хранения и управляет им сам.

## Состояние

Проект находится на этапе проектирования. Рабочего плагина и сервера пока нет. Эта папка фиксирует принятые решения, открытые вопросы и порядок реализации, чтобы дальнейшие изменения можно было проверить.

## Цель первой версии

Установить плагин на компьютер и телефон, подключить один и тот же удалённый vault и синхронизировать заметки, вложения и выбранные настройки через GitHub или личный VPS. Первый публичный релиз также должен включать историю версий, восстановление, конфликты и общие vault. [Базовый MVP](docs/MVP.md) остаётся внутренним этапом проверки, а не публичным релизом.

Синхронизация — не резервная копия. В проекте будут отдельные инструкции по созданию и восстановлению копий данных.

## Сеть и учётные записи

Будущий плагин будет подключаться напрямую к GitHub API в режиме GitHub либо к адресу VPS, который укажет пользователь. Для первого режима нужен аккаунт GitHub и приватный репозиторий; для второго — собственный сервер. Аккаунт проекта не потребуется. Пока плагина нет, эти подключения не выполняются. Клиентская телеметрия не планируется.

В GitHub-режиме файлы остаются читаемыми в приватном репозитории. В VPS-режиме для первого релиза запланировано шифрование на устройстве до отправки; безопасность этих двух режимов различается.
