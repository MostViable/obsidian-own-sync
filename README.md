# Own Sync for Obsidian

Own Sync — независимый проект плагина для Obsidian. Он не связан с командой Obsidian. Основной сценарий — синхронизация через **свой сервер на VPS** с шифрованием данных на устройствах. Приватный репозиторий GitHub рассматривается как дополнительный способ хранения с читаемыми Markdown-файлами **после self-hosted релиза**. Пользователь управляет своим хранилищем сам.

## Состояние

Проект находится на этапе проектирования. Рабочего плагина и сервера пока нет. Эта папка фиксирует принятые решения, открытые вопросы и порядок реализации, чтобы дальнейшие изменения можно было проверить.

## Цель первой версии

Установить плагин на компьютер и телефон, подключить один и тот же vault на личном VPS и синхронизировать заметки, вложения и выбранные настройки. Первый публичный релиз также должен включать историю версий, восстановление, конфликты и общие vault. [Базовый MVP](docs/MVP.md) остаётся внутренним этапом проверки, а не публичным релизом.

Синхронизация — не резервная копия. В проекте будут отдельные инструкции по созданию и восстановлению копий данных.

## Сеть и учётные записи

Будущий плагин будет подключаться к адресу VPS, который укажет пользователь. Для этого нужен собственный сервер; аккаунт проекта не потребуется. Запланированный после первого релиза GitHub-режим потребует аккаунт GitHub и отдельный приватный репозиторий. Пока плагина нет, эти подключения не выполняются. Клиентская телеметрия не планируется.

В первом релизе запланировано шифрование на устройстве до отправки на VPS. В более позднем GitHub-режиме файлы будут оставаться читаемыми в приватном репозитории; безопасность этих двух режимов различается.
